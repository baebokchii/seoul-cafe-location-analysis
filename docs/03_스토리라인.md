# 03. 스토리라인 (SCQA · 피라미드 · 고스트 덱)

분석 결과를 보고서로 옮기기 전에 이야기의 뼈대를 먼저 정합니다. 결론을 맨 앞에 두고(피라미드 원칙), 슬라이드 제목(액션 타이틀)만 이어 읽어도 이야기가 되게 만듭니다.

## 1. SCQA

| | 내용 |
|---|---|
| **S** 상황 | 서울에서 카페 1곳을 운영하는 소규모 브랜드가 2호점을 준비 중 |
| **C** 문제 | 서울 카페 시장은 손님 2년째 정체(−1.8%), 카페 수도 정점 대비 −5.2%. 손님이 늘어난 상권은 28%뿐 |
| **Q** 질문 | 손님이 늘고, 카페 한 곳의 몫이 커지며, 임대료까지 감당할 수 있는 2호점 입지는 서울 어디인가? |
| **A** 답 | **대치역·방이역·천호역** 중 한 곳. 계약 전 3개월 동안 임대료·폐점 사유·가격 경쟁을 확인해 1곳으로 좁힘 |

## 2. 피라미드

```
핵심 메시지: 2호점은 대치역·방이역·천호역 중 한 곳이 적합하며,
            계약 전 3개월 동안 임대료·폐점 사유·가격 경쟁을 확인해 1곳으로 좁혀야 한다
│
├─ ① 수요: 세 곳의 손님은 2년간 25~80% 늘었다 (서울 전체 −1.8%)
├─ ② 경쟁: 세 곳 모두 카페 한 곳이 받는 손님이 53~77% 늘었다
├─ ③ 수익성: 대치역·방이역은 매출 상위권이고, 세 곳 모두 임대료가 서울 평균의 0.85~1.22배다
├─ ④ 지속성: 다음 1년도 현재 수준이 유지될 전망이다 (오차 ±15~25%)
└─ ⑤ 위험과 권고: 위험이 곳마다 달라(폐점 원인·가격 경쟁·낮은 매출) 계약 전 확인할 일이 다르다
```

②~④의 근거는 이슈 트리의 갈래(A1, A2, A3, B1)와 1:1로 대응합니다.

## 4. 슬라이드 작성 원칙

- **한 장에 메시지 하나.** 제목이 그 메시지이고, 본문(차트·표)은 제목의 근거입니다.
- **제목은 결론 문장으로.** "손님 증가율" 같은 주제어가 아니라 "세 곳의 손님은 2년간 25~80% 늘었다"처럼 숫자가 들어간 주장으로 씁니다.
- **아래쪽 강조 상자 = So what.** 이 장에서 대표님이 기억할 한 줄, 그리고 가설 판정(→ H1 채택 등)을 적습니다.
- **출처는 장마다.** 모든 숫자는 노트북 출력과 같아야 하고, 출처 줄에 데이터 이름을 적습니다.
